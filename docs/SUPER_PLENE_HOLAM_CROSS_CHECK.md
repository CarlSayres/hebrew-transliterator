# Super-Plene Holam–Alef–Vav Cross-Check

## Scope and decision

The whole-Tanakh mater lectionis audit found 34 distinct pointed forms (74 occurrences) with this sequence:

1. a consonant carrying holam;
2. an unvocalized alef;
3. an unmarked vav.

The first implementation review incorrectly described these as if a spelling pattern alone established pronunciation. This cross-check instead compares every form with a pronunciation source, lexical entry, parallel pointed form, or traditional transliteration.

All 34 forms belong to ten lexical groups. In every group, the evidence supports **one pronounced `o` across the holam–alef–vav sequence**. The alef and vav may be retained in letter-for-letter scholarly romanization, but they do not create `o·o` in the phonetic output used by this application.

## Implementation consequence

The runtime rule remains structural: an unmarked vav after silent alef, when the preceding consonant already carries holam, is not repaired into an additional holam-vav. An explicitly vocalized second vav remains a second vowel—for example, רִבֹּא֖וֹת is `ribo·ot`. A shuruk likewise remains pronounced. This preserves the distinction actually encoded by the pointing instead of maintaining a growing word-exception list.
